# Build prompt

This is a reusable implementation prompt authored for this release. It is not a verbatim export of the private development conversation.

> Build a React and TypeScript landing-page hero around a dimensional workflow deck. Use the included DimensionalWorkflowHero component as the reference implementation. Start with three angled panels in a single perspective scene. As the visitor scrolls, pin the hero and bring each panel forward while displaying its chapter heading and three readable steps. Animate workflow nodes and connector signals in sequence. For the build chapter, transition from a database table to illustrative React code and then a finished-site preview. End with a pullback and a clear CTA. Use GSAP ScrollTrigger with cleanup on unmount. Keep the stage animation on transforms and opacity. Preserve chapter position on desktop resize and when switching to static mode. Provide semantic chapter navigation, a skip link, visible keyboard focus and a Simplify motion button. Mobile and prefers-reduced-motion must show the same content as a readable static sequence. Keep styles scoped, use real product content supplied by the owner, and do not invent metrics or client claims. Avoid em dashes. Preserve the rest of the host page. Test desktop, mobile, keyboard navigation, reduced motion, resizing and route unmount/remount before shipping.
