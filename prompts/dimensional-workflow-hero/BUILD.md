# Build prompt

This reusable prompt is authored for the collection. It is not an export of the private development conversation.

> Build a React and TypeScript hero around a dimensional deck using the supplied DimensionalWorkflowHero as reference. Keep the motion component independent of the example content. Accept a title, introduction and one to five chapter objects with React panel slots. Start with angled, overlapping panels. Pin the hero on desktop and bring each panel forward as its chapter appears. End with an optional pullback and CTA. Use scoped GSAP and ScrollTrigger cleanup, transforms and opacity. Scale the visual scene into desktop embeds without scaling the pin measurements. Preserve the active reading position on desktop resize. Include semantic chapter buttons, a skip link and visible keyboard focus. Small screens and reduced-motion preferences must show the same content as a static sequence. No stored motion override is needed. Use real content supplied by the owner, keep CSS scoped and avoid em dashes. Test desktop, mobile, keyboard navigation, resizing, reduced motion and multiple instances.

The full workflow renderer with database, code and finished-site scenes remains in `examples/full-workflow-showcase/` for projects that need that complete presentation.
