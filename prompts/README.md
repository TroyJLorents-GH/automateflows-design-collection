# Prompt collection

Keep each reusable prompt beside the component or example it produces. Published prompts are edited instructions for reuse, not private conversation logs, credentials or client documents.

For the published hero, start with the [short installation prompt](dimensional-workflow-hero/INSTALL.md). BUILD.md is for recreating the design, and ADAPT.md is for customizing its implementation.

For a new design, add a named folder with BUILD.md, ADAPT.md and a link to its example. Record model or tool versions only when measured or verified.
